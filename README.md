# 💰 KBC Style Quiz Game

A "Kaun Banega Crorepati" (KBC) inspired quiz game built with **Streamlit**, where players answer general knowledge questions to climb a prize ladder — one wrong answer ends the game.

## 🖥️ Features

* 11 multiple-choice general knowledge questions
* Prize money ladder from ₹1,00,000 up to ₹60,00,000
* Progress bar showing how far along the quiz you are
* Instant feedback on correct/incorrect answers
* Game-over screen showing final prize won
* Balloons animation on winning any prize 🎈
* "Play Again" option to restart the game

## 🛠️ Tech Stack

* **Python**
* **Streamlit** — for the interactive web UI
* Session State — to track current question, score, and game status



## 🎮 How to Play

1. Read the question and select an option (a/b/c/d)
2. Click **Lock Answer**
3. Correct answer → move to the next question and prize increases
4. Wrong answer → game ends immediately, showing the correct answer
5. Click **Play Again** to restart from question 1

## 📌 Note

Questions and prize amounts are hardcoded in the script and can be easily edited or expanded to add more rounds.
