# Quiz-Game
# 🎯 KBC Style Quiz Game - Kaun Banega Crorepati

A fun and interactive KBC-inspired quiz game built with Python and Streamlit. Answer questions, win virtual prize money, and test your knowledge!

### 🚀 Live Demo
**Play the game here:** https://quiz-game-pahsltrzstznbxo2wgqbzc.streamlit.app/

---

### ✨ Features
- KBC-style gameplay with increasing prize money
- 11 General Knowledge questions
- Interactive UI with Radio buttons and Lock system
- Instant feedback on correct/wrong answers
- Total winnings display and Restart option

- ### 🛠️ Tools
- **Python**
- **Streamlit**
